# 🚀 Деплой на Render.com

Пошаговая инструкция по деплою AI Chat Application на Render.com

## 📋 Подготовка

### 1. Зарегистрируйтесь на Render.com
- Перейдите на [render.com](https://render.com/)
- Зарегистрируйтесь через GitHub

### 2. Подготовьте репозиторий
- Загрузите ваш проект в GitHub репозиторий
- Убедитесь, что все файлы загружены

## 🔧 Настройка на Render

### 1. Создание нового сервиса
1. Войдите в панель Render
2. Нажмите **"New +"** → **"Web Service"**
3. Подключите ваш GitHub репозиторий

### 2. Настройки сервиса
```
Name: my-chat-app
Environment: Node
Region: Oregon (US West)
Branch: main
Root Directory: (оставьте пустым)
```

### 3. Build & Deploy настройки
```
Build Command: chmod +x build.sh && ./build.sh
Start Command: chmod +x start.sh && ./start.sh
```

### 4. Переменные окружения
Добавьте следующие переменные в разделе **Environment Variables**:

```
NODE_ENV = production
PORT = 10000
GIGACHAT_API_KEY = ваш_api_ключ_gigachat
OPENROUTER_API_KEY = ваш_api_ключ_openrouter
YANDEX_CLOUD_API_KEY = ваш_api_ключ_yandex
YANDEX_CLOUD_FOLDER_ID = ваш_folder_id_yandex
```

## 🚀 Деплой

### 1. Запуск деплоя
1. Нажмите **"Create Web Service"**
2. Render автоматически начнет сборку
3. Дождитесь завершения (обычно 5-10 минут)

### 2. Проверка
После успешного деплоя:
- Ваше приложение будет доступно по URL вида: `https://my-chat-app.onrender.com`
- Проверьте health check: `https://your-app.onrender.com/health`

## 🔧 Альтернативный способ (через render.yaml)

Если у вас есть файл `render.yaml`:

1. В настройках сервиса выберите **"Infrastructure as Code"**
2. Укажите путь к файлу: `render.yaml`
3. Render автоматически применит настройки

## 📊 Мониторинг

### Логи
- В панели Render перейдите в раздел **"Logs"**
- Просматривайте логи в реальном времени

### Метрики
- **"Metrics"** - использование ресурсов
- **"Events"** - события деплоя

## 🔄 Обновления

### Автоматические деплои
- Render автоматически деплоит при push в main ветку
- Можно настроить другие ветки в настройках

### Ручные деплои
- Нажмите **"Manual Deploy"** в панели
- Выберите нужную ветку или коммит

## 💡 Полезные советы

1. **Бесплатный план ограничения**:
   - Приложение "засыпает" после 15 минут неактивности
   - Первый запрос после сна может занять 30+ секунд

2. **Оптимизация**:
   - Используйте кэширование где возможно
   - Минимизируйте размер зависимостей

3. **Безопасность**:
   - Никогда не коммитьте .env файлы
   - Используйте Environment Variables в Render

3. Проверьте правильность переменных окружения
4. Обратитесь в поддержку Render
