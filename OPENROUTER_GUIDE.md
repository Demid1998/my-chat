# OpenRouter Integration Guide

## Что такое OpenRouter?

[OpenRouter](https://openrouter.ai/) - это универсальный интерфейс для работы с множеством LLM моделей через единый API. Через OpenRouter вы можете получить доступ к:

- **60+ провайдерам** AI моделей
- **500+ моделям** от разных компаний
- **Единому API** для всех моделей
- **Лучшим ценам** и доступности

## Доступные модели через OpenRouter

### OpenAI
- `openai/gpt-4o` - Самая продвинутая модель с мультимодальными возможностями
- `openai/gpt-4o-mini` - Быстрая и эффективная модель
- `openai/gpt-3.5-turbo` - Классическая модель для общего использования

### Anthropic
- `anthropic/claude-3.5-sonnet` - Продвинутая модель с отличными возможностями рассуждения
- `anthropic/claude-3-haiku` - Быстрая модель для простых задач

### Google
- `google/gemini-pro-1.5` - Модель с большим контекстным окном (до 2M токенов)

### Meta
- `meta-llama/llama-3.1-8b-instruct` - Открытая модель для интерактивного использования
- `meta-llama/llama-3.1-70b-instruct` - Мощная открытая модель

### Mistral
- `mistralai/mistral-7b-instruct` - Эффективная модель для интерактивного использования

### DeepSeek
- `deepseek/deepseek-chat` - Модель с отличными возможностями программирования

## Настройка OpenRouter

### 1. Регистрация
1. Перейдите на [OpenRouter](https://openrouter.ai/)
2. Зарегистрируйтесь через Google, GitHub или MetaMask
3. Создайте аккаунт

### 2. Получение API ключа
1. В личном кабинете перейдите в раздел "API Keys"
2. Создайте новый API ключ
3. Скопируйте ключ

### 3. Пополнение баланса
1. Перейдите в раздел "Credits"
2. Пополните баланс (минимум $1)
3. Выберите подходящий план

### 4. Настройка в проекте
Добавьте API ключ в файл `server/.env`:

```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

## Использование в приложении

### Выбор модели
1. Откройте настройки чата (кнопка ⚙️)
2. В разделе "Модель AI" выберите нужную модель из группы "OpenRouter - Множество моделей"
3. Сохраните настройки

### Особенности OpenRouter моделей
- **Полная совместимость** с OpenAI API
- **Поддержка всех параметров**: temperature, max_tokens, top_p, frequency_penalty, presence_penalty
- **Потоковые ответы** (stream)
- **Системные сообщения**
- **История разговоров**

## Ценообразование

OpenRouter использует гибкую систему ценообразования:
- **Pay-per-use** - платите только за использованные токены
- **Лучшие цены** - часто дешевле чем у оригинальных провайдеров
- **Прозрачные тарифы** - все цены указаны на сайте
- **Бесплатные модели** - некоторые модели доступны бесплатно

## Преимущества OpenRouter

1. **Единый API** - не нужно изучать разные API для разных провайдеров
2. **Высокая доступность** - автоматический fallback при недоступности провайдера
3. **Лучшие цены** - оптимизированные тарифы
4. **Быстрая работа** - edge-инфраструктура добавляет всего ~25ms задержки
5. **Безопасность** - настраиваемые политики данных

## Мониторинг использования

В личном кабинете OpenRouter вы можете:
- Отслеживать использование токенов
- Просматривать историю запросов
- Настраивать лимиты расходов
- Получать уведомления о балансе
