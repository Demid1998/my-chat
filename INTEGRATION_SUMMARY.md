## Как использовать

### 1. Добавить OpenRouter API ключ
```bash
# Отредактируйте файл server/.env
OPENROUTER_API_KEY=sk-or-v1-your_actual_api_key_here
```

### 2. Перезапустить сервер
```bash
cd server
npm start
```

### 3. Выбрать модель в интерфейсе
- Откройте настройки (⚙️)
- Выберите модель из группы "OpenRouter - Множество моделей"
- Сохраните настройки
